# Miglė Cirtautaitė

**Backend and embedded developer · Computer Science at KTU · Co-founder of [Thunderclap Labs](https://thunderclaplabs.com)**

I build backend services and the systems around them: REST APIs in Spring Boot and ASP.NET Core on PostgreSQL and MySQL, C services on OpenWrt routers, and firmware for ESP32 and STM32 boards. At Thunderclap Labs, a student R&D startup at Kaunas University of Technology, I work on embedded systems and hardware prototypes.

[migle.cirtautai.lt](https://migle.cirtautai.lt) · [thunderclaplabs.com](https://thunderclaplabs.com)
